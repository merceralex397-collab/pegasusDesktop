# Desktop parity matrix

The repository-derived feature-parity matrix required by proposal §23. One
row per observable capability, keyed by the Razor page model and handler
group that implements it today. Pre-populated on 2026-08-23 from the fork at
`main` `191ddf33`; the tickets in [README.md](README.md) § 5 (DSK-01-01 to
DSK-01-05) complete and re-verify every row.

## Legend

Status ladder (proposal §23, plus one added state):

| Status | Meaning |
| --- | --- |
| `not inventoried` | Row exists but entry point, behaviour evidence, or test evidence is still missing |
| `inventoried` | Entry point, handlers, behaviour evidence, FRD owner, and at least one test file are recorded |
| `designed` | Native screen/use case specified in area 06 and endpoint named in area 03 |
| `implemented` | Native code exists on a branch |
| `automated verification passed` | Unit/contract/UI automation evidence recorded |
| `UAT passed` | Named UAT owner signed off |
| `cut over` | Desktop is the path in use; web path disabled in the Test/UAT stack |
| `legacy path retired` | Web page removed |
| `legacy path retained` | Deviation from §23: the surface deliberately stays server-side (external/anonymous or consent pages) |

Required evidence per row (proposal §23.1): current screenshot or behavioural
description; current route/controller/service/entity references; approved
native design; cloud-placement decision; automated test result; manual/UAT
result; data comparison where applicable; known deliberate difference;
rollback path. Columns below hold the pointers; the evidence itself lives in
the ticket proof.

Column notes:

- **Current entry point** — page model path under `src/Pegasus.Web/Pages/`
  and its handlers (`OnGet`/`OnPost*`); line counts from the 2026-08-23
  inventory.
- **API/data dependency** — Core use cases/ports the page calls today and
  the indicative `/api/v1` endpoint family that area 03 defines. Names
  prefixed `~` are indicative, not decided.
- **UAT owner** — left blank for the operator to assign.
