## What

Move the pure code → operator-label map out of `src/Pegasus.Web/Presentation/OperatorLabels.cs` into `src/Pegasus.Contracts` so the web app and the desktop consume one vocabulary list, and re-point the twenty-four `.cshtml` consumers without any behaviour change.

## Why

`AGENTS.md` § Simplicity rails: "One list per concept. An exception taxonomy, a state vocabulary, a label table, a precedence order lives in exactly one place. A second copy in another layer is duplication even when it is 'just strings'." The desktop needs the same labels the web renders; without this move it would grow a second map, and the two would drift the first time a business word changed. Operator-visible consequence: an operator sees the same words for the same state in the web app and the desktop, permanently. This is a **deviation** the plan records explicitly — the proposal is silent on it, and the repository rule requires it.
