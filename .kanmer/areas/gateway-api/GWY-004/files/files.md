## Ripple effects

- **The whole CI restore graph.** A new package on `Pegasus.Web` and (if scaffolded here) a new test
  project each require a committed `packages.lock.json`; `--locked-mode` in the shared composite action
  makes a miss fail every lane.
- **The `unit` job's contract and its comment.** Appending a third `&&`-chained project changes what
  the job runs and falsifies its header comment. Both edits belong in this change.
- **[[GWY-002]]'s gate-off fact extends to the document.** With `Features:DesktopGateway` off,
  `/openapi/v1.json` must 404 like everything else under the gate. Add that assertion where
  [[GWY-002]]'s composition test already asserts the gate, or as a fact here — but assert it, because
  registering `AddOpenApi` globally is an easy mistake that nothing else catches.
- **[[GWY-005]] (plan handle `DSK-03-05`) consumes `openapi/pegasus-v1.json` directly.** Its Kiota
  generation, its committed client and its CI no-op check all key off the file this ticket commits and
  the script directory this ticket creates. A change to the normalisation rules after [[GWY-005]] lands
  re-generates the whole client.
- **Every later `GWY` endpoint ticket now has a second gate.** From this point, adding or changing an
  endpoint changes `openapi/pegasus-v1.json`, and the PR must carry the regenerated file. That is the
  intended coupling and it should be stated in `docs/index.md`'s new row so it is discoverable.
- **`src/Pegasus.Contracts` gains no reference.** The transformer lives in `Pegasus.Web`; the
  architecture fact from [[GWY-001]] fails if an ASP.NET Core reference reaches Contracts.
- **Documentation.** `docs/index.md` only. `scripts/Test-DocumentationLinks.ps1` runs in the
  `documentation` lane and checks the link added.
