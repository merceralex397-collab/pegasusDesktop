## What

Register a versioned `/api/v1` route group inside `src/Pegasus.Web/Program.cs` behind a new `Features:DesktopGateway` composition gate, with RFC 9457 problem-details mapping ported from `AutomationMcpErrors.cs`, `X-Correlation-Id` accept/generate/echo, and the hook where the `X-Pegasus-Client-Version` check (owned by area 04) plugs in.

## Why

Proposal § 10.2 requires one versioned REST API with feature-based route groups, standard problem responses and correlation identifiers; L-01 says that API is `Pegasus.Web` evolved in place, not a new deployment unit. The gateway today has no JSON surface at all beyond `GET /diagnostics/version` and the health endpoints. Operator-visible consequence: until this lands, no desktop screen can call anything; after it lands, an unconfigured deployment still serves exactly the web app it serves today, because a closed composition gate is a disabled flag rather than a shipped feature. [[DSK-03-03]] hangs authorization off this group; [[DSK-03-04]] documents it.

6. Add `src/Pegasus.Web/Api/DesktopGatewayProblems.cs`: an `IExceptionHandler` (registered with `AddProblemDetails()` + `AddExceptionHandler`) scoped to the group that maps, one branch per Core exception, using the `ProblemTypes` constants from `src/Pegasus.Contracts`: `StaffAuthorizationException` → 403 `not-authorized`; `CaseVersionConflictException` → 409 `version-conflict` with `currentVersion = ActualVersion`; `CaseEditLeaseConflictException` → 409 `lease-conflict` with `currentVersion = CaseVersion`; `CaseEditLeaseExpiredException` → 409 `lease-expired` with `currentVersion = CaseVersion`; `CaseOperationConflictException` → 409 `operation-conflict`; `ArgumentException`/`InvalidOperationException`/`InvalidDataException` → 400 `validation`; `OperationCanceledException` → rethrow (client abort); anything else → 500 `maintenance`-free generic problem carrying no exception text. Copy the message discipline from `AutomationMcpErrors.cs:19-70`: a domain refusal names the guard and the current version, an unexpected failure collapses to a generic message.
7. Add `src/Pegasus.Web/Api/CorrelationIdEndpointFilter.cs` applied to the root group: read `X-Correlation-Id` when present and well formed (≤ 200 characters, no control characters), otherwise generate one from `HttpContext.TraceIdentifier`; echo it on the response header and put it in every problem body's `correlationId`. Add a `TODO`-free extension point (a named no-op filter registration) where [[DSK-04-06]] inserts the `X-Pegasus-Client-Version` check — do not implement the version check here.

Add `builder.Services.AddProblemDetails()` in `src/Pegasus.Web/Program.cs` only if it is not already registered, and confirm the addition does not change Razor Pages error behaviour: `Pages/Error.cshtml.cs` and `Pages/StatusCode.cshtml.cs` must still render (see the `IsMachineSurface` re-execute guard at `Program.cs:968-975`).
