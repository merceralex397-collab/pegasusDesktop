## What

Establish the shared contract vocabulary inside `src/Pegasus.Contracts` (the project `DSK-02-04` scaffolds): DTO naming and shape conventions, the RFC 9457 problem-type catalogue, the paging envelope, and the explicit `expectedVersion` / `editLeaseToken` / `operationKey` fields every `/api/v1` command body carries — plus an architecture test that keeps the project free of EF Core, ASP.NET Core and WinUI references.

## Why

Proposal § 10.3 makes the OpenAPI document the contract and forbids hand-written duplicate DTOs; § 10.4 requires an explicit concurrency token on every mutable aggregate. Without one contracts project, the desktop and the gateway grow separate record shapes and separate error vocabularies, breaking the "one list per concept" rail in `AGENTS.md` § Simplicity rails. Operator-visible consequence: a version conflict, a lease expiry and a validation refusal reach the desktop as three distinct stable `type` URIs, so the client can offer reload, reacquire or correct instead of one generic failure. Every later ticket in this epic — [[DSK-03-02]] through [[DSK-03-18]] — compiles against what this ticket defines.

5. Add `src/Pegasus.Contracts/Paging/PagedResult.cs`: `Items`, `Page`, `PageSize`, `HasPreviousPage`, `HasNextPage`, and an optional `TotalCount` that is null unless the backing query port already counts (`SearchCasesResult` at `src/Pegasus.Core/Cases/CaseQueries.cs:69` does not). Record `pageSize` maximum 200 as a constant, and note in XML docs that a per-endpoint cap may be lower — `ListIntake` at `src/Pegasus.Core/Intake/IntakeQueryUseCases.cs:24` refuses a page size above 100.
6. Add `src/Pegasus.Contracts/Commands/CommandEnvelope.cs` defining the three concurrency/idempotency members every command body carries as explicit fields, never headers: `operationKey` (string), `expectedVersion` (long) and `editLeaseToken` (string) — mirroring `CaseMutationRequest`. Document the desktop key format `desk:<guid>` with the same constraints `RequireOperationKey` enforces (≤ 100 characters, no whitespace, no control characters; 200 only where Core allows, e.g. `src/Pegasus.Core/Intake/Unidentified/UnidentifiedContracts.cs:398`).
7. Write the conventions as a doc comment on a `ContractConventions` marker type in the project (not a new `.md` file — a Markdown file outside `docs/(prd|frd|adr|design|desktop)` fails the CI `documentation` job): DTO suffixes `Request`/`Response`, no Core record is exposed directly (they carry `ActionActor` and server-only members), enum values serialise as strings, dates are `DateTimeOffset` in UTC.

Extend `tests/Pegasus.ArchitectureTests/DependencyDirectionTests.cs` with a `ContractsHasNoInfrastructureOrHostDependencies` fact that asserts the `Pegasus.Contracts` assembly references none of `Microsoft.AspNetCore*`, `Microsoft.EntityFrameworkCore*`, `Microsoft.WindowsAppSDK`/`Microsoft.UI.Xaml`, `Pegasus.Core`, `Pegasus.Infrastructure`, `Pegasus.Web`, `Pegasus.Worker` — reusing the existing `IsForbiddenCoreDependency` helper shape rather than writing a second matcher.
