## What

Add a `ProvenanceGlyph` control that shows where a value came from as one Lucide glyph whose tooltip — on hover **and** on keyboard focus — is exactly one word, with a matching accessible name, drawn from the seven-word map the web already uses.

## Why

The web partial `src/Pegasus.Web/Pages/Shared/_Provenance.cshtml` replaced prose in a third column plus a policy key and a version integer, none of which an operator can act on; the row must still make sense with the icon ignored. Operator-visible consequence: a keyed value versus an extracted value versus a lookup value is distinguishable without reading a code, and a keyboard user gets the same information as a mouse user. Consumes [[DSK-06-03]] and [[DSK-06-05]]; consumed by the Case create, Received item and Vehicle screens.

## Implementation steps

1. Orientation. Read the plan row, `src/Pegasus.Web/Presentation/OperatorLabels.cs:618-637` and `src/Pegasus.Web/Pages/Shared/_Provenance.cshtml`. Call Kanmer `get_doc_gates` for this ticket id, then `take_ticket`.
2. Load `pegasus-desktop`, then `winui-design`. Search `microsoft_docs_search` for showing a `ToolTip` on keyboard focus in WinUI 3 — the platform shows tooltips on hover by default and focus behaviour must be verified, not assumed.
3. Add `src/Pegasus.Desktop/Controls/ProvenanceGlyph.cs`: a focusable (`IsTabStop="True"`) templated control taking the same source value the web partial takes, calling the **shared** `OperatorLabels.Provenance` for the `(word, glyphKey)` pair. Do not restate the seven pairs in the desktop.
4. Map the returned `icon-*` key to the corresponding `PegasusIcon*` resource from [[DSK-06-03]] through one lookup, so a glyph rename happens in one place.
5. Tooltip: `ToolTipService.SetToolTip` with the single word; ensure it also appears on keyboard focus (handle `GotFocus`/`LostFocus` and show/hide the tooltip explicitly if the platform does not). Set `AutomationProperties.Name` to the same word so the tooltip and the accessible name always match.
6. Only the seven words plus `Unknown` may appear: `Staff`, `Extracted`, `AI`, `E-mail`, `Lookup`, `Principal`, `Automatic`. Add a view-model test asserting the desktop returns the same word as `OperatorLabels.Provenance` for every `CaseDataSourceKind` value, including the AI-reader branch.
7. The glyph is supplementary: assert in the reviewer checklist that every row carrying a provenance glyph still reads correctly with the glyph removed, and that no permanent consequence is communicated by the glyph alone (`docs/design/README.md:409`).
8. Build and run with `pwsh .codex/skills/winui-dev-workflow/BuildAndRun.ps1 src/Pegasus.Desktop/Pegasus.Desktop.csproj`; render all eight provenance states on the gallery page from [[DSK-06-02]].
9. Load `winui-ui-testing` and write `tests/Pegasus.Desktop.UITests/provenance-tests.ps1`: `winapp ui hover` each glyph and `wait-for` the tooltip text; then `focus` each glyph with the keyboard and `wait-for` the same text; assert `Name` equals the word in both cases.
10. Narrator smoke: tab onto a provenance glyph in a form row and confirm the single word is announced and nothing else.
