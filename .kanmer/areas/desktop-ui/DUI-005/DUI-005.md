## What

Make the desktop consume the relocated shared operator-label map for every state, date, size and code it displays, and add view-model tests that fail the build when a raw `enum.ToString()`, GUID, hash, version integer or byte count reaches XAML, or when a value has no mapping. The same test set covers the entry side: an identifier is chosen from a named picker, never typed, and no raw aggregate identifier reaches a Target or reference column.

## Why

`src/Pegasus.Web/Presentation/OperatorLabels.cs` is the single place a persisted code becomes words (`docs/design/README.md:588`), and the "one list per concept" rail (`AGENTS.md` § Simplicity rails) makes a second desktop copy a stop condition. Operator-visible consequence: the desktop says `Not ready`, `Blocked`, `Review` in the same settled casing as the web, and every time renders Europe/London rather than the workstation zone (`ToLocalTime()` is never correct — `docs/design/README.md:171`). Upstream `PLAT-015` records the other half of the same defect, and on the fork board nothing else owns it: the web still ships "Assignee ID"/"Engineer ID" GUID text inputs and a typed "Report SHA-256" input in `src/Pegasus.Web/Pages/Cases/Shared/_CaseWorkflow.cshtml`, a "Case ID" GUID input on Triage detail, a reply picker showing `InternetMessageIdentity`, and a raw `AggregateId` in the Automation Activity Target column. An operator cannot type a key they never see, and a Target column carrying one names nothing. [[DSK-05-22]] step 9 reviews that copy on the sweep side; this ticket makes the desktop's own build fail on it. Consumed by [[DSK-06-06]], [[DSK-06-10]], [[DSK-06-11]] and every slice.

## Implementation steps

1. Orientation. Read the plan row, `docs/desktop/06-ui-design/README.md` § 3 Additional decisions, and `src/Pegasus.Web/Presentation/OperatorLabels.cs` in full. Confirm whether `DSK-05-23`/`DSK-03-16` have landed and which assembly now owns the map; if neither has, stop and record the block. Call Kanmer `get_doc_gates` for this ticket id, then `take_ticket`.
2. Load `pegasus-desktop`, then `code-testing-agent`. Add a project reference from `src/Pegasus.Desktop` (and `src/Pegasus.Desktop.Infrastructure`) to the assembly that now owns `OperatorLabels`. Do not copy the file, do not re-implement `Humanise`, and do not add a desktop-side switch expression over the same enums.
3. Add a single desktop-side formatting facade — one static class, e.g. `src/Pegasus.Desktop/Presentation/OperatorText.cs` — that delegates every call to the shared map and adds only what the desktop needs on top: the Europe/London date and time formats. It must expose no second vocabulary of its own.
4. Implement time formatting by copying the resolution pattern proved in `src/Pegasus.Web/Pages/Shared/_FreshnessBanner.cshtml`: `TimeZoneInfo.FindSystemTimeZoneById("Europe/London")`, catching `TimeZoneNotFoundException` and `InvalidTimeZoneException`, falling back to UTC **and labelling it UTC** rather than claiming London. Never call `DateTimeOffset.ToLocalTime()` anywhere in the desktop.
5. Route every view-model display property through the facade: stage, case type, document role and origin, custody, upload-link state, history event, file size, provenance word, classification, refresh state. A view model exposes a `string` the view binds directly; the XAML performs no conversion.
6. Add `tests/Pegasus.Desktop.ViewModelTests/OperatorVocabularyTests.cs` with a theory over every enum the desktop displays, asserting each member maps to a non-empty label that is not the member name. Done looks like: adding a new enum member with no mapping turns the test red.
7. Add `NoRawCodeReachesTheView`: reflect over every public property of every view model that is bound in XAML and fail on a returned type of `Guid`, `Enum`, `byte[]`, `int` used as a version, or a string matching `^[A-Za-z]+(_[a-z]+)+$` (snake_case event codes) or a PascalCase compound. Where a numeric value is legitimately displayed (a count), the property must be a pre-formatted `string`.
8. Add the entry-side companion to step 7, which inspects output properties only (upstream `PLAT-015`) — two facts in the same file. (a) `NoIdentifierEntryReachesTheView` reflects over every settable, two-way-bindable property of every view model bound in XAML and fails on a type of `Guid`, `Guid?` or `byte[]`, and on any property whose name ends `Id`, `Identifier` or `Hash`; it also scans `src/Pegasus.Desktop/**/*.xaml` and fails on a `TextBox` whose `Header` or `AutomationProperties.Name` matches `ID`, `Id`, `identifier`, `GUID`, `SHA-256` or `hash`. An identifier is chosen, never typed: the view model exposes a picker collection sourced from `ActorDisplayNames` (`src/Pegasus.Core/Actors/ActorDisplayNames.cs`) or `IStaffAccountQueries` (`src/Pegasus.Core/Identity/StaffAccountAdministration.cs:110`), binds the display name and keeps the key internal. (b) `NoRawAggregateIdentifierReachesATargetColumn` fails on any Target or reference column bound to a property step 7 already classes as a raw code — a Target resolves to the Case or PO reference, or the column is omitted. Done looks like: adding an "Engineer ID" `TextBox`, a typed `Report SHA-256` field or a `Guid` two-way property turns exactly these facts red.
9. Add `EuropeLondonFormattingIsUsed`: assert a `DateTimeOffset` of `2026-06-15T13:00:00Z` renders as `14:00` (BST) and one of `2026-01-15T13:00:00Z` renders as `13:00` (GMT), through the facade. This is the BST date the plan row's acceptance names.
10. Add `NoBannedWordReachesTheOperator`: assert that no string produced by the facade or by any view-model display property contains any of `intake`, `bounded`, `projection`, `lease`, `opaque`, `ingress`, `composed`, `artifact`, `durable`, `aggregate`, `caller`, `correlation identifier`, `bytes` (case-insensitive, word boundary) — the closed list at `docs/design/README.md:412-420`. Note that these words remain valid as code identifiers; the ban is on what an operator reads.
11. Run `dotnet test tests/Pegasus.Desktop.ViewModelTests`. Load `run-tests` if the harness needs shard or filter guidance. Fix every failure by adding the mapping to the **shared** map, never by adding a desktop-local special case.
12. Reviewer grep for the PR: `rg -n "\.ToString\(\)|ToLocalTime\(\)|DateTime\.Now" src/Pegasus.Desktop --glob '!**/obj/**'` must return nothing in view or view-model display paths. Record the grep output in the post-implementation report.

## Acceptance criteria

- [ ] The desktop references the one shared `OperatorLabels` map; no second vocabulary list exists in the desktop projects.
- [ ] No `enum.ToString()`, GUID, hash, version integer or byte count reaches XAML.
- [ ] Every date and time renders Europe/London, verified with a BST date and a GMT date; `ToLocalTime()` appears nowhere.
- [ ] A persisted value with no mapping fails the view-model tests.
- [ ] No banned word appears in any operator-facing string produced by the desktop.
- [ ] No identifier is typed anywhere: a staff, case, engineer or evidence identifier is chosen from a named picker sourced from `ActorDisplayNames`/`IStaffAccountQueries`, never entered as a key or a hash, and no raw aggregate identifier appears in a Target or reference column — it resolves to the Case or PO reference, or the column is omitted (upstream `PLAT-015`). The companion test over bound input properties fails the build when either rule is broken.
