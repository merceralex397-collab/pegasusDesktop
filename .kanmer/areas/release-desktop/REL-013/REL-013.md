## What

Write the one-page first-install guide for workstations — runbook **R7** distilled into operator vocabulary — covering prerequisites, the required certificate-trust step, opening the channel's `.appinstaller`, first launch, the blocked states, where diagnostics live, and how to switch channel. This ticket **owns** that one-pager and its path, `docs/desktop/09-release-update-and-distribution/first-install.md`; [[DSK-04-13]] contributes the startup-sequence and blocked-state content it names in operator words.

## Why

Proposal § 24 Phase 9 requires training users with concise workflow guidance, and § 26 lists the operational documents the conversion owes. The install has one step that will otherwise fail for everyone: D-002's self-managed certificate must be trusted on the machine **before** the package arrives, or the install fails with `0x800B0109` — a code no operator can act on. `docs/design/README.md` is design authority for this repository and forbids how-it-works copy: the page says what to do, not how updates work. [[DSK-04-13]] writes the fuller technical first-run guide for support and prerequisites; the two documents have different audiences, which is why both exist and why neither restates the other.

4. Write the prerequisites section from R7's checklist, in operator vocabulary: Windows 11 x64 (24H2 recommended) with current updates, signed in as the person who will use Pegasus (per-user install, no administrator needed once the signing chain is trusted); Microsoft Edge WebView2 runtime present (default on Windows 11; check in Settings → Apps); network access to the Pegasus files location and to Pegasus itself. Keep it to the checklist — the fuller prerequisites reference is [[DSK-04-13]]'s and is linked, not copied.
5. Make the certificate-trust step prerequisite **number one on the page**, not buried: import the public `.cer` into `Cert:\LocalMachine\TrustedPeople` (elevated, once per machine) or let Group Policy deliver it, then verify with `certutil -verifystore TrustedPeople`. Add the one operator-actionable sentence: if the app was installed before this step it fails — do this step, then install again.
6. Write the four steps from R7: open the channel's `.appinstaller` from the Pegasus files location and choose Install; sign in with the existing Pegasus account on first launch; check Settings/Diagnostics shows the version, channel and Pegasus address; record the workstation in the support register (user, machine, channel, date).
7. Write the blocked states in operator words only — what the person sees and what they do — sourced from [[DSK-04-13]]'s startup-sequence and blocked-state content (and from `docs/desktop/06-ui-design/screen-specs.md` § *Update required / Blocked* if that guide has not landed). Say what to do; do not explain the startup order — that is [[DSK-04-13]]'s page and this one links to it.
8. Add the uninstall/reinstall and channel-switch paragraphs from R7: Settings → Apps → Pegasus → Uninstall, then repeat the install steps; switching channel is uninstall then install from the other channel's `.appinstaller`.
9. Close with the one-page skeleton exactly as the plan words it — operator vocabulary only, no how-it-works copy: **Install · Sign in · Pegasus updates itself on launch · If you see "Update required", close and reopen · If you see "Cannot reach Pegasus", check the network and retry · Export diagnostics from Settings when asked by support.**
10. Add the managed-device note as a support-facing line, not user copy: `ms-appinstaller:` stays disabled (it is not needed) and App Installer auto-update must not be disabled by policy — support checks `Get-AppxPackageAutoUpdateSettings` after install. Record the expected policy state for the estate. In `runbooks.md` § R7 this ticket records **only** the link to the one-pager and that expected managed-device policy state; the cross-link to the technical guide and any R7 step the clean-machine reproduction proved wrong are [[DSK-04-13]]'s to record, so the two tickets never write the same R7 line.
11. Add one honest expectation-setting line about SmartScreen: a warning may appear on the first download of a new version; it is expected in an in-house estate and is not a signing failure.
12. **Operator step** — have a pilot user who did **not** write the page follow it end to end on a clean or reset workstation, and hand back where they hesitated. Fix the page against what actually confused them; that feedback is the acceptance evidence, not the author's own read-through.
