## What

Write the one-page first-install guide for workstations — runbook **R7** distilled into operator vocabulary — covering prerequisites, the required certificate-trust step, opening the channel's `.appinstaller`, first launch, the blocked states, where diagnostics live, and how to switch channel.

## Why

Proposal § 24 Phase 9 requires training users with concise workflow guidance, and § 26 lists the operational documents the conversion owes. The install has one step that will otherwise fail for everyone: D-002's self-managed certificate must be trusted on the machine **before** the package arrives, or the install fails with `0x800B0109` — a code no operator can act on. `docs/design/README.md` is design authority for this repository and forbids how-it-works copy: the page says what to do, not how updates work.

## Implementation steps

1. Orient: read `runbooks.md` § R7 **in full**, then `docs/design/README.md` for the operator-copy rules. Call Kanmer `get_doc_gates` on this ticket id, then `take_ticket`.
2. Check for an existing owner before writing: [[DSK-04-13]] also produces a first-run/initial-install guide. Search the board (`search_items` for `first-install`) and agree **one** canonical document; if [[DSK-04-13]] already wrote it, this ticket reviews and folds R7's certificate-trust and channel-switch material into it instead of creating a second page. Record the decision in `open-questions/` before step 3.
3. Create the page at `docs/desktop/09-release-update-and-distribution/first-install.md` — inside an allowed Markdown root, so the CI `documentation` job passes. Do not put it in `docs/guides/` or the repository root.
4. Write the prerequisites section from R7's checklist, in operator vocabulary: Windows 11 x64 (24H2 recommended) with current updates, signed in as the person who will use Pegasus (per-user install, no administrator needed once the signing chain is trusted); Microsoft Edge WebView2 runtime present (default on Windows 11; check in Settings → Apps); network access to the Pegasus files location and to Pegasus itself.
5. Make the certificate-trust step prerequisite **number one on the page**, not buried: import the public `.cer` into `Cert:\LocalMachine\TrustedPeople` (elevated, once per machine) or let Group Policy deliver it, then verify with `certutil -verifystore TrustedPeople`. Add the one operator-actionable sentence: if the app was installed before this step it fails — do this step, then install again.
6. Write the four steps from R7: open the channel's `.appinstaller` from the Pegasus files location and choose Install; sign in with the existing Pegasus account on first launch; check Settings/Diagnostics shows the version, channel and Pegasus address; record the workstation in the support register (user, machine, channel, date).
7. Add the uninstall/reinstall and channel-switch paragraphs from R7: Settings → Apps → Pegasus → Uninstall, then repeat the install steps; switching channel is uninstall then install from the other channel's `.appinstaller`.
8. Close with the one-page skeleton exactly as the plan words it — operator vocabulary only, no how-it-works copy: **Install · Sign in · Pegasus updates itself on launch · If you see "Update required", close and reopen · If you see "Cannot reach Pegasus", check the network and retry · Export diagnostics from Settings when asked by support.**
9. Add the managed-device note as a support-facing line, not user copy: `ms-appinstaller:` stays disabled (it is not needed) and App Installer auto-update must not be disabled by policy — support checks `Get-AppxPackageAutoUpdateSettings` after install. Record the expected policy state for the estate.
10. Add one honest expectation-setting line about SmartScreen: a warning may appear on the first download of a new version; it is expected in an in-house estate and is not a signing failure.
11. **Operator step** — have a pilot user who did **not** write the page follow it end to end on a clean or reset workstation, and hand back where they hesitated. Fix the page against what actually confused them; that feedback is the acceptance evidence, not the author's own read-through.
12. Run `pwsh ./scripts/Test-DocumentationLinks.ps1` and `pwsh ./scripts/Test-TestMarkdownPlacement.ps1` — both must exit `0`. Request review by `pegasus-desktop-reviewer` and record the dated `## Simplification pass` (`n/a — docs-only`).
