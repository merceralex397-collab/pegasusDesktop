## What

Create the desktop unit-test project `tests/Pegasus.Desktop.ViewModelTests` (`net10.0-windows10.0.26100.0`, x64, xunit) that exercises view models and desktop infrastructure **without a `DispatcherQueue`**, with one shared set of fakes — gateway API client, `TimeProvider`, credential store — and first tests covering shell navigation and status-bar state.

## Why

Proposal § 22.2 puts view-model tests in the pyramid and § 24 Phase 1 requires foundation tests to pass before the gate. Plan § 4 lists the project in the target solution shape, and [[DSK-02-06]], [[DSK-02-07]], [[DSK-02-08]], [[DSK-02-10]] and [[DSK-02-11]] all need a Windows-target test home: `ProtectedData`, `ApplicationData` and `Package.Current` cannot be tested from the `net10.0` `tests/Pegasus.ArchitectureTests` project. Area 08 adds the decision that desktop tests share one `FixedTimeProvider` rather than per-file copies (an explicit deviation from copying fakes). Operator-visible consequence: without this project the desktop's behaviour is only ever proven by launching the app by hand, which does not scale past the first slice.
