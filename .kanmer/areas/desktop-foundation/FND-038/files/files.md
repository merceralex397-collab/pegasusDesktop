## Ripple effects

- **Architecture test**: `ApplicationSolutionExcludesSourceWorkspaces` fails until the new
  path is added to its expected array — that is the fact doing its job, and the fix belongs
  in this ticket's diff.
- **Lock-file / restore**: a new `packages.lock.json` changes the composite action's NuGet
  cache key (`.github/actions/dotnet-build/action.yml`, `cache-dependency-path`). Every
  building lane takes one cache miss on the first run after merge. Expected, and worth saying
  in the proof so nobody reads it as a regression.
- **CI coverage gap**: `.github/workflows/ci.yml:145-147` does **not** run this project.
  Tests merged by this ticket are not enforced by CI until [[FND-040]] adds `desktop-build`.
  The proof states this rather than implying coverage.
- **Blocked tickets**: [[FND-041]] (plan handle `DSK-02-16`) runs this suite for its
  "Foundation tests pass" gate row; [[FEAT-001]] and the whole of area 04's desktop side
  ([[FND-043]], [[FND-044]], [[FND-045]]) write their tests into this project.
- **[[TEST-004]]** is the same scaffold in area 08 and must not create it a second time.
- **No contract ripple.** This ticket touches no endpoint, no DTO and no serialized shape, so
  `openapi/pegasus-v1.json` and the generated client — the usual ripple on this board — are
  untouched. Recorded so the reviewer sees it was checked.
- **No documentation ripple.** The ticket's own Documentation-changes section says the
  evidence-tier wording for `winapp ui` and packaging proofs is coordinated by area 08, not
  here.
