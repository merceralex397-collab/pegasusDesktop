## What

Author and accept two conversion ADRs: `docs/adr/0102-existing-pegasus-credentials-token-session.md` (existing Pegasus credentials, desktop session = short-lived access token + rotated refresh token) and `docs/adr/0105-msix-app-installer-and-minimum-version-gate.md` (signed MSIX/App Installer distribution with a gateway minimum-version gate), each carrying the six-answer cloud-justification table, and add their rows to `docs/adr/README.md`.

## Why

Every Phase 2 ticket in this area — [[DSK-04-02]] through [[DSK-04-15]] — needs a governing decision record before it can leave Backlog, and proposal §8.2 and §9.1 are the two decisions the whole phase rests on. Without ADR-0102 an implementing agent has no recorded authority for the password/refresh grant choice; without ADR-0105 the two-layer update enforcement (package + gateway gate) is only planning text. The operator-visible consequence is that a wrong token or update decision is discovered after workstations are installed, when the package identity and feed path can no longer change.

6. Fill ADR-0102's cloud-justification table with all six questions from `docs/desktop/00-governance-and-workflow/README.md` § 3 and a yes/no plus evidence for each. Shared authority = yes (one account store), central enforcement = yes (revocation, roles, audit independent of the client); the remaining four are answered from the same evidence. "It is already in Azure" is not an answer.

The Decision states the two-layer enforcement of proposal § 9.1: (a) signed MSIX delivered by an `.appinstaller` on the 2021 schema with `OnLaunch HoursBetweenUpdateChecks="0" ShowPrompt="true" UpdateBlocksActivation="true"`, and (b) a gateway minimum-version gate whose minimum is a database-backed Administrator setting with audit, with a `Desktop:MinimumClientVersion` configuration value used only for bootstrap. Record explicitly that App Installer fails **open** when the feed is unreachable and the gateway gate is the fail-closed layer with a 24-hour cache that must not be extended.
8. In ADR-0105's *Context* and *Consequences*, record D-002 (self-managed certificate trusted per workstation in `LocalMachine\TrustedPeople`, certificate subject equals the manifest `Publisher` exactly and is fixed before the first package), D-003 (UNC feed over SMB, so `Uri` values read `\\<host>\<share>\<channel>\Pegasus.appinstaller`) and C-01 (private repositories rule out GitHub Releases and Pages permanently).
